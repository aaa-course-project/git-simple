# Git实验笔记
## 命令理解
### git add
将工作目录的修改添加到**暂存区**，标记需要提交的改动，改动尚未存入版本库。

### git commit
把暂存区的改动生成快照，保存到**本地版本库**，生成提交记录；仅保存在本机，不会上传远程仓库。

### git restore
用暂存区或版本库中的文件，覆盖工作目录，丢弃工作区未暂存的修改。
- `git restore 文件名`：撤销工作区修改
- `git restore --staged 文件名`：将文件从暂存区移出

## 三大工作区
1. 工作目录：直接编辑文件的区域
2. 暂存区：临时存放待提交修改
3. 版本库：`.git`目录，保存完整版本历史

## 第一次Git实验总结
1. git add 的作用是：将工作区的文件改动添加到暂存区，标记这些修改准备提交。
2. git commit 的作用是：把暂存区的改动保存到本地Git仓库，生成一条带备注的提交记录。
3. git restore notes.md 的作用是：撤销工作区未暂存的修改，将文件恢复到最近一次commit的版本。
4. commit 与 push 的区别是：commit仅保存到**本地仓库**；push把本地提交上传到**远程GitHub仓库**。
